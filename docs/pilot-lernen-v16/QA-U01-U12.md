## 2. Temuan Gagal / perlu perbaikan

### QA-V16-01 — P1 — Empat potret avatar tidak terdekode (U02)
- **[P] Skenario:** profil baru → `Mulai cerita` → layar "Siapa kamu di kota ini?" → periksa 4 potret `player-01`…`player-04`.
- **Aktual [P]:** kelima `<img>` (1 pratinjau + 4 pilihan) `complete=true`, **`naturalWidth=0`**. Network `responseReceived` untuk keempat URL `http://tauri.localhost/a1-story/actors/player-0X/neutral.webp` = **status 200**, tipe `Image`. Tidak ada `loadingFailed`.
- **Harapan:** empat potret produksi tampil (U02); tokoh terpilih muncul di adegan berikutnya.
- **Bukti:** `konfirmasi-temuan.json` → `steps.U02-gambar.imgs` & `network`; `qa-u01-u12-inti.json` → `steps.U02.imgs` (`decoded:0`); screenshot `screenshots-u01-u04/U02-avatar.png`.
- **Pemisahan:** (b) dekode media **gagal**; (c) pemutaran runtime tidak terbukti. HTTP 200 membuktikan tersedia, bukan terdekode.
- **Pemilik yang disarankan:** **integrator** (packaging/path runtime aset `a1-story/actors/`), **UI** bila format WebP tidak didukung WebView2.
- **Kriteria terima:** keempat potret `naturalWidth>0` & `complete=true` pada EXE revisi; tokoh terpilih tampil di panggung; bukti [P] DOM + screenshot; `console.error=0`.

### QA-V16-02 — P2 — Tombol "Dengar suara" tidak teramati (U02)
- **[P] Skenario:** pada layar pilih karakter, cari kontrol dengar contoh "Hallo!" untuk avatar yang dipilih; probe `play` dipasang sebelum klik.
- **Aktual [P]:** dump tombol hanya `Kembali` dan `Mulai prolog`; tidak ada tombol/aria-label mengandung "Dengar", "Hallo", atau "suara". `window.__m.plays` tidak bertambah saat interaksi avatar.
- **Harapan:** *Dengar suara* memutar "Hallo!" dari ID avatar; memilih avatar lain menghentikan contoh sebelumnya (brief §4).
- **Bukti:** `qa-u01-u12-inti.json` → `steps.U02.hear=null`, `before=1`, `after=1`; `rekon-u02-u03.json` → `steps.dengar-avatar.kandidat=[]`.
- **Batas bukti:** kemungkinan kontrol hanya muncul setelah potret benar-benar terdekode (lihat QA-V16-01); saya belum dapat membedakan. Tidak saya nyatakan sebagai cacat mandiri sebelum dekode diperbaiki.
- **Pemilik:** **UI / Media**.
- **Kriteria terima:** kontrol tersedia & ber-`aria-label`; probe sebelum klik merekam satu `play` per avatar; ganti avatar menghentikan klip sebelumnya.

### QA-V16-03 — P2 — Jalur "Latih keterampilan → Peron berubah" tidak tercapai dari jalur uji (U05–U08)
- **[P] Skenario:** dari story/title, cari `Latih keterampilan`, `Ruang belajar A1–B2`, `Peron berubah`, `Bab 11`.
- **Aktual [P]:** tombol-tombol itu tidak ditemukan di DOM yang saya capai. `Ruang belajar A1–B2` sempat menampilkan `Menyiapkan data…/Menyiapkan aplikasi…` dan tidak selesai dalam jendela tunggu saya. - **Bukti:** `qa-u05-u12.json` → `steps.ruang-belajar`, `steps.cari-peron`; `u05-u12-final.json` → `steps.latih`, `steps.peron`.
